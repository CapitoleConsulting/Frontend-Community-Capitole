This section contains essential patterns and best practices that every Angular developer should know. Learn how to structure your code for maintainability, scalability, and testability.

## Pattern Guides

### Design Patterns
**[Design Patterns](./design-patterns.md)** — Seven essential patterns for Angular development:
- Singleton Pattern — Global state management
- Facade Pattern — Simplifying complex subsystems
- Factory Pattern — Dynamic object creation
- Strategy Pattern — Runtime algorithm switching
- Dependency Injection — Loose coupling
- Observer Pattern — Reactive updates
- Decorator Pattern — Metadata & behavior

### SOLID Principles
**[SOLID Principles](./solid-principles.md)** — Five fundamental design guidelines for maintainable code:
- **S**ingle Responsibility Principle — One reason to change per class
- **O**pen/Closed Principle — Open for extension, closed for modification
- **L**iskov Substitution Principle — Subtypes must honor parent contracts
- **I**nterface Segregation Principle — Segregate large interfaces
- **D**ependency Inversion Principle — Depend on abstractions, not implementations
